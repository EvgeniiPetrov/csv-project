# CSV Project — анализ измерений насосной станции

Учебный проект на Python для чтения, проверки и анализа измерений насосного оборудования из CSV-файлов.

## Возможности

- Чтение CSV-файлов с разделителем-запятой в кодировке UTF-8 средствами стандартной библиотеки Python.
- Проверка обязательных столбцов: `timestamp`, `pump_id`, `pressure_mpa`, `temperature_c`. Дополнительные столбцы допускаются.
- Проверка измерений и разделение записей на корректные и отклонённые.
- Группировка корректных измерений по идентификатору насоса.
- Расчёт количества измерений, минимального и максимального давления, среднего давления и средней температуры по каждому насосу.
- Сохранение итогового отчёта `report.csv` с сортировкой по `pump_id`.
- Вывод итоговой статистики обработки в консоль.

## Формат входных данных

| Столбец | Описание | Допустимые значения |
| --- | --- | --- |
| `timestamp` | Дата и время измерения | `YYYY-MM-DD HH:MM:SS` |
| `pump_id` | Идентификатор насоса | Непустая строка |
| `pressure_mpa` | Давление, МПа | От 0 до 2 включительно |
| `temperature_c` | Температура, °C | От −40 до 150 включительно |

## Запуск

Из корневого каталога репозитория:

```bash
python src/csv_project/main.py
```

Путь к входному CSV-файлу задаётся переменной `input_csv_file` в файле [`main.py`](src/csv_project/main.py). Отчёт `report.csv` сохраняется в текущем рабочем каталоге.

Сторонние библиотеки не требуются.
