# CSV Project — обработка измерений насосной станции

Учебный проект на Python для чтения, проверки и анализа данных измерений насосного оборудования из CSV-файлов.

## Возможности

- Чтение CSV-файлов с помощью стандартной библиотеки Python.
- Проверка обязательных столбцов: `timestamp`, `pump_id`, `pressure_mpa`, `temperature_c`.
- Валидация даты и времени, идентификатора насоса, давления и температуры.
- Разделение записей на корректные и ошибочные.
- Группировка измерений по идентификатору насоса.
- Расчёт минимального, максимального и среднего давления, средней температуры и количества измерений.
- Вывод результатов обработки в консоль.

## Структура входных данных

| Поле | Описание |
|---|---|
| `timestamp` | Дата и время (`YYYY-MM-DD HH:MM:SS`) |
| `pump_id` | Идентификатор насоса |
| `pressure_mpa` | Давление, МПа (0–2) |
| `temperature_c` | Температура, °C (−40…150) |

Дополнительные столбцы допускаются.

## Запуск

Из корневого каталога проекта:

```bash
python src/csv_project/main.py
```

Путь к входному CSV-файлу задаётся в переменной `input_csv_file` внутри программы.

Используется стандартная библиотека Python. Установка сторонних зависимостей не требуется.

## Текущее состояние

Реализованы чтение, валидация, группировка и расчёт статистики.

**В разработке:** сохранение результатов в `report.csv`, сортировка итогового отчёта по `pump_id` и итоговая сводка обработки.
