Учебные файлы для ТЗ-01 «Обработка журнала измерений насосной станции»

Во всех CSV: 100 строк данных + 1 строка заголовков; кодировка UTF-8, разделитель — запятая.
Столбцы: timestamp,pump_id,pressure_mpa,temperature_c
timestamp: YYYY-MM-DD HH:MM:SS; pump_id: непустой;
pressure_mpa: 0..2.0; temperature_c: -40..150.

measurements_clean.csv — 100 корректных записей.
measurements_minor_errors.csv — 95 корректных и 5 ошибочных записей.
measurements_bad.csv — 75 корректных и 25 ошибочных записей.

Ошибки реалистичные: пустые поля, текст вместо числа, значение вне диапазона,
некорректная дата или отсутствующий идентификатор насоса.
Исходные файлы не требуется менять: некорректные строки следует исключать из расчетов.

В папке CHECK_AFTER_SOLUTION — контрольные результаты (JSON).
Рекомендуется сначала выполнить задание самостоятельно и только затем открыть проверку.
